## 需要使用者在GitHub完成的設定

程式與設定已準備好；目前連線無法代改以下項目：

1. Repository Settings → General → Change visibility：依你的最新決定改為Public。這會使所有branch、`live-data`及已保存runtime狀態都能被任何人讀取；只限組員寫入的權限另由collaborators控制。教師ZIP／Yahoo原始資料的再散布授權尚未核實，不假稱已獲來源許可。
2. Settings → Default branch：改為`system-completion`，main的空樹與歷史仍保留；如此GitHub才會從正確分支註冊schedule。
3. Settings → Secrets and variables → Actions：安全設定`COURSE_EMAIL`、`COURSE_PASSWORD`。值不要貼聊天或寫進repo。Live公開key由官方前端取得，不需重新貼key。

完成後還要實跑採集，核實教師來源成功、排查FRED網路／TLS、確認定時run，再處理正式模型與提交驗收；不是完成設定就算整套服務合格。
