## 已確認的問題定義

目標是 open-to-close，不是昨收至今收，也不是隔夜跳空。外部市場訊號可能先反映在台股開盤價，因此「能解釋台股跳空」不代表「能預測台股盤中方向」。用相同時點的 walk-forward 驗證檢查增益。

起初使用者希望先看建議與選項；2026-10-25進一步授權在`dev`下載Graphify技能、先建專案圖，再實作市場特徵。2026-10-27明確要求開始既定流程，並重申整體目標為增加經濟／市場序列、每日04:00～09:00自動更新教師與額外資料並建立模型、計算指數報酬特徵。採ML系統生命週期分層；成熟現成工具優先，避免重複造輪子。

每日訓練建立候選模型，僅用已完成且截止前可用的歷史標籤；比較時將現有配置與候選在相同較早train重訓，再對相同validation鍵評分。通過檢查才升級，失敗／超時保留相容且已驗證版本。自動提交50檔預測CSV並核實回執已獲使用者授權，不重問相同行動；不包含公開原始資料。

目前已實作四類模型×三目標研究、每日stage、raw→daily表橋接、推論、提交與回執程式；前端POST契約已核實、官方state／模板已唯讀實測，但尚無真實POST、正式模型或常駐排程。未提供表路徑時自動準備七個個股滯後特徵；今日08:10前已取得的私有bytes能證明今日可用，不代表歷史調整價當時可用。strict訓練仍blocked，研究opt-in只產research_assumption，不能升級或提交。M0／SOX／ADR消融未顯示增益，額外來源未自動納入正式表。

使用者希望不依靠學校主機，改以雲端排程完成。當前對話沒有Tasks／排程工具，不能宣稱聊天關閉後代理可自行執行；已有systemd及Actions設定可審查，正式執行器／持久儲存仍待落實。main空樹且未更改default branch；workflow_dispatch與schedule皆須workflow存在default branch。
