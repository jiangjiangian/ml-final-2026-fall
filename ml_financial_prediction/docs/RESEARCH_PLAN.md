# 每日自動ML系統與Return-ratio研究執行計畫

狀態：使用者已要求實作；不是整體已上線的宣告。實際結果、命令、限制以STATUS、EXPERIMENTS及各研究報告為準。正式競賽規範優先，工作於dev，保留main空樹。

## 目標與驗收

每天Asia/Taipei 04:00～09:00取得教師＋額外市場資料，核對時間與品質、產生特徵、候選訓練／驗證、50檔預測、09:00前自動提交並確認回執。原始資料不公開。自動提交授權沿用D020；端點、格式、截止與回執要實際驗證，不能以HTTP200或排程檔存在宣稱成功。

研究與正式執行分開：有明示假設的歷史實驗可以探索，但不能被標成已核實point-in-time，更不能直接升級為正式提交模型。

## 系統與資料研究

1. 重用TWSE、TAIFEX、FinMind、MIS、GDELT既有紀錄及教師／Live下載器，不重問使用者已提供API。逐來源核實權限、完整歷史、自動取得規則、單位、更新／修訂時間與授權。
2. 起步保留IXIC／GSPC／TWII／KS11、VIX及TX_OI，擴充SOX、TSM ADR／NVDA、匯率／利率及台灣產業；其他市場與商品後續逐組消融。SOX不等於SOXX／SMH，海外個股不冒稱指數。
3. 保留不可變原始快照與每次manifest，原生日曆先算報酬，再按cutoff與版本對齊。未知值、來源休市與停更分開；OI／殖利率／VIX不一律套價格報酬。
4. 日期、發布及修訂證據不足時標示來源缺口。只能在明示假設的研究分支使用保守時間政策，不把當前下載／最新還原價歷史當成歷史vintage證據。

## Return-ratio研究

主目標固定為`mean((2*p-1)*(adj_close-adj_open)/adj_open)`。每個指定股票均輸出0/1，不自行只選top-k。

- 特徵比較：個股滯後基準→加入M0→逐組加入額外來源；報酬lag／累積、歷史波動、缺值與陳舊、產業交互作用各自消融。
- 目標比較：普通方向分類、逐樣本abs(return)加權分類、直接報酬回歸後取符號。權重只由已完成歷史label生成，訓練fold內正規化，不能成為當日輸入。
- 四家族：正則化線性、梯度提升樹、MLP、GRU；優先成熟scikit-learn與PyTorch CPU。先用預註冊小型設定及seed42，不先做大規模搜尋。
- 基準：全部0、全部1、僅由訓練集決定的多數類別；同時計算accuracy及官方score，模型選擇以後者為主。
- 時間：2020–2024起始訓練，2025分季向前驗證，2026年1–5月保留檢查；前處理只fit訓練集，同日股票不跨fold。保留期不反覆調參，Phase1既有標籤不當排行榜選參工具。
- 保存所有嘗試、負結果、逐月分數、缺值、耗時與資料／程式版本；不把無交易成本官方score稱為投資淨利。

## 每日工作流與模型升級

契約：原始快照→標準化觀測與可用性報告→版本化特徵／獨立labels→訓練表→前處理與模型包→CSV→回執。模型包保存schema／順序、訓練範圍、資料與程式hash、seed及時間政策；推論不fit。

初始時程：04:17／05:17／06:17／07:17取得資料；07:20凍結訓練、07:50停止；07:55決定升級；08:10特徵凍結；08:20前預測與初次提交；08:35前核實／重試；09:00停止。這是待實測預算，不是所有來源04點已齊的保證。

候選與現有設定以同一時間切分重新訓練／比較，不能把已看過驗證日期的現有權重冒充樣本外基準。初始bootstrap或換配置須嚴格提高官方score；同一已核實配置若有新增完成歷史、可信incumbent metadata、schema／政策相容且同fold不退步，可例行refresh，不要求勝過相同配置自己的refit。通過比較後才對截止前完成歷史fit正式模型。來源未核實、失敗／超時則沿用相容已驗證舊版，無舊版明確blocked。

正式主機原先選學校Linux；使用者後續詢問是否可改雲端排程。當前工具沒有可設定此對話的Tasks／排程工具，不能承諾聊天結束後本代理自行常駐。保留systemd部署與Actions手動演練兩種入口；Actions正式cron需處理default branch、持久儲存及截止延遲，不擅自改main／default branch或宣稱已啟用。Kaggle先比較、不登入／不傳課程資料。

五階段CLI、候選／推論／提交與raw→daily表橋接已實作。未供表時train／predict會自動準備七個個股滯後特徵；08:10前實際取得可證明當日可用，不能倒填歷史。strict歷史訓練因發布／調整vintage未核實仍blocked；研究opt-in只產研究表，不以手填verified略過。額外來源已採集，E01～E03同fold消融未顯示增益，未自動加入正式daily表。Actions的workflow_dispatch同樣要求workflow存在default branch，不能只處理cron而忽略手動入口。
