## 結論草稿（每一項是那份筆記的重點）

### 架構和宣稱的績效

- 已發表的系統（TradingAgents、FinMem、FinAgent、FinCon、StockAgent、QuantAgent 等）都是同一個樣子：分析師角色的 LLM 讀新聞、基本面、技術面，辯論或交給經理，交易員出買賣，再加記憶和反思。幾乎都停在回測的模擬成交，GitHub 星數最多的專案自己寫不下真單。
- 漂亮的數字來自很小的樣本：3～8 檔挑過的美股大型股、3～8 個月，大多沒寫交易成本，常在 LLM 的訓練期內。別的團隊拉長期間、放寬股票、換到截止日後重跑，優勢縮小或消失。
- 研究、辯論、決策、文字反思有實作；真的下單、依流動性決定部位、硬性風控、交易後稽核幾乎都缺。真錢的例子只有比賽（Alpha Arena）和小型個人專案，而且都在 LLM 和券商中間放寫死的程式。
- 機構的用法是讓 LLM 做研究（Man Group 產生和寫訊號程式、Balyasny 讀文件），核准、風控、下單由人和既有系統負責；沒有找到稽核過的公開績效。

### 嚴謹的評估

- FINSABER（arXiv 2505.07078，引用用 v6；v6 更正過 FinAgent 的數字，結論不變）：2004～2024、含下市股的 S&P 500 成分股，LLM 策略（FinMem、FinAgent）輸買進持有，也輸 ARIMA，alpha 不顯著。多頭太保守、空頭太積極。
- 2025 年起的即時基準（StockBench、DeepFund、AI-Trader、Agent Market Arena、LiveTradeBench）多半 1～4 個月、4～100 檔、沒算成本，多數模型和買進持有差不多或更差。LiveTradeBench：通用能力排名和股票報酬的 Spearman 相關只有 0.054。
- 真錢比賽 Alpha Arena 兩季 38 個帳戶（每個 1 萬美元），31 個虧錢，合計虧約 27%～28%，手續費約本金的 11%；每季只跑兩週多，贏家換季就變。
- LLM 記得訓練期的行情：GPT-4o 對截止日前 S&P 500 點位方向對約 81%，截止後 46%（等於丟銅板）；叫它假裝不知道沒有用。agent 回測跨過截止日，報酬和 Sharpe 掉五到七成。例外是「新聞情緒 → 隔日報酬」這種窄任務，用時點一致的模型重做後前視偏誤很小。
- 2023～2025 年 164 篇金融 LLM 論文，承認前視偏誤的 26.8%，處理存活者偏誤的 1.2%。
- 統計門檻：年化 Sharpe 1 的策略要約 970 個交易日才到 5% 顯著，80% 檢定力要約 1,980 天。3～6 個月的即時比賽分不出技巧和運氣。

### LLM 做訊號和研究自動化

- LLM 讀新聞的訊號在美國資料有效，但能交易的部分很小，集中在小型股和壞消息，2021 年起逐年變小，來回成本約 20 bp 就消失；大型股樣本外每天約 6～17 bp（扣成本前、當天有新聞的股票）。
- 隔夜新聞大多已經反映在開盤價，開盤到收盤剩下的漂移很小，大型股最弱。
- 台灣的證據很少，沒有找到現成的公開歷史新聞資料集，也沒有研究用公開資訊觀測站或 PTT。
- 只看價格序列：Chronos、TimesFM 零樣本的方向準確率 50%～51%、樣本外 R² 為負，輸給梯度提升。
- 研究自動化 agent（RD-Agent、AlphaAgent）在自己的論文對 Qlib 基準贏很多，大多是中國 A 股；後來的論文換新期間重跑，優勢大多消失，沒有中立的重現。風險是搜尋大量候選造出假贏家、LLM 記得回測期、只報最好的那次。學生跑得動（API 費用 10 美元以下），但預設環境是 Linux、Docker、Qlib 的中國資料，沒有台股或開盤到收盤目標的現成做法。

### 免費和小模型

- 2026-11 還能確認「零成本、會續、額度公開」的免費 API 只剩 Cloudflare Workers AI（每天 10,000 neurons）、OpenRouter `:free`（所有免費模型合計每天 50 次）、Gemini 免費層（台灣可用，額度官方不公開，額度內也可能回 429，部分專案要手機驗證，免費層沒有 Google 搜尋）。GitHub Models 2026-07-30 關閉；Hugging Face、Cerebras 取消會續的免費額度。免費層一路在縮，設計上一定要有「沒有 LLM 也能交件」的退路。
- 4 核 CPU 跑 7B～8B 的 4-bit 模型，每秒 3～6 個 token，50 檔要約 7 小時；Kaggle T4 放得下 9B～14B。Colab 免費版不能排程。
- 通用能力強不代表交易好；小模型的明確弱點在多步驟：柏克萊 BFCL V4（2026-04-12）Qwen3-8B 多輪 41.75%、網路搜尋題 12%，Claude Opus 4.5 是 68.38% 和 84.5%。單次工具呼叫 8B～32B 有 85%～89% 正確。所以流程要寫死，模型只把文字變成固定欄位的分數。
- 英文金融情緒 8B 開放模型就夠（Qwen3 8B 零樣本 0.82 對 GPT-4o 0.85）；繁體中文知識題 7B～8B 比前沿模型低約 16～20 分，70B 級追平。金融專用開放模型多半輸同大小的新通用模型。
- 免費的時點一致模型有 ChronoBERT／ChronoGPT（1999～2024 每年一版）、PIT 系列，都是英文、最大 4B。

### 台股實務和法規

- 券商 API：永豐 Shioaji、富邦新一代 API 文件最完整、Python 可用；Shioaji 有模擬環境（不支援零股），富邦有不用開戶的測試環境（成交要自己下反向單、帳務常不正確、09:30～19:00）。兩家文件都沒有正面寫 API 免費，也沒有收費條款。
- 開盤買、收盤賣就是現股當沖：手續費牌告買賣各 0.1425%，當沖證交稅 0.15%（到 2027-12-31），一趟牌告 43.5 bp，手續費打 2.8 折約 23 bp。15 bp 的稅壓不下去。
- 當沖要資格（開戶滿三個月、近一年成交滿十筆、簽風險預告書），只限整股和當沖標的；零股不能當沖（金管會 2026-04-28 說在評估）。50 檔各一張通常要數百萬元的額度。
- 個人用 API 自動下自己的錢合法；紅線是別人的錢和收費建議（沒有執照做投顧或代操最重五年徒刑）。
- 免費資料：證交所 OpenAPI（含每日重大訊息，2026-11-20 觀察到約 05:20～05:24 更新）、FinMind、富果；中文新聞有 CNA、鉅亨、聯合、MoneyDJ、Yahoo 的 RSS 和 PTT 的 Atom。排程主機只有學校的 oop 有準時的 cron。

## 查證時發現的更正（寫報告時照這些改）

- Alpha Illusion 的「55 個比較贏 44 個」是讀錯，原文是 5 檔裡 4 檔；照表 3 是 10 個「股票 × agent」比較，買進持有贏 8 個。
- GPT-4o 方向正確率：S&P 500 是截止前 80.58%、截止後 45.70%。
- FINSABER 的 p = 0.0117 是動能選股那列，隨機 5 檔是 7.7e-4；alpha 檢定只有動能和低波動兩種選股。
- StockBench 的「沒算手續費和滑價」是 v2 才加的；它的摘要和內文互相矛盾。
- Alpha Arena 第一季不要引用 ForkLog 的數字，用創辦人結束公告的截圖。
- BFCL 只能用官方 CSV 的數字，d-central.tech 的 Qwen3.5、Gemma 4 分數要刪。
- 0.1425% 不是法定上限，是牌告，超過要事先通知客戶；20 元低消是券商自訂。
- 兩個 QuantAgent 是不同系統（arXiv 2402.03755 和 2509.09995）。
