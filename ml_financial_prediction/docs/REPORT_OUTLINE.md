## 已有四種方法與新架構的界線

既有E00已實際完成四家族：正則化線性、HistGradientBoosting、MLP、小型GRU；各比較普通分類、`abs(return)`加權分類及raw-return回歸取正負。這些結果可作為目前報告的方法與實驗材料。新研究另設計Ridge／提升樹／causal TCN／市場引導跨股attention；只有在程式、完整feature panel、因果測試及真實比較完成後，才把TCN／attention列成已驗證實驗。

每種方法至少填：輸入欄位版本、前處理只fit train、loss／超參數／seed、訓練截止、日期切分、樣本全集、官方score、accuracy、耗時、警告與重跑命令。模型名稱不同不自動形成有效比較；相同label、可用資料、股票日期鍵與預算才可比較。

## 每日操作與Phase1的最後驗收

1. Phase1使用官方84日期模板與50股全集，逐日期只用當時可用資訊；不能把現在已下載的答案或事後修訂值當成當時feature。若無合格來源／模型，保留blocked，不靠已知label造完美CSV。
2. 每日服務逐session保存raw版本、真實取得時間、feature cutoff、模型／程式版本、候選選擇理由、50股CSV及與state目前版本吻合的回執；模擬測試與真實運作分開。
3. 至少五個真實官方交易日dry run按實際日期累積；晚到／失敗／回退也記錄。不能在2026-10-31一次捏造五個後續session。
4. 最終報告只總結已執行結果，明列仍未驗證的歷史發布、來源授權與模型外推；人工確認作者、引用、規範與PDF頁數後，再在已授權範圍交付。
