# memory/projects

每一條工作線的設計、進度和結果，一條線一個檔：爬蟲、特徵、每個 Kaggle 研究系列。

- 新的工作線開新檔，用下一個號碼（`NN-名字.md`，NN 是建立的順序）。刪掉的號碼空著，不重新編號。完整的規則在 `memory/README.md`。
- 自動研究（`/goal`、`/loop`）每一輪先讀的狀態檔，和它的專案檔分開，檔名用 `-state` 結尾。狀態檔只放現在的階段和下一步，數字和判斷寫在專案檔。
- 一個檔超過約 1,000 行時，把已經結束的段落搬到 `NN-名字-archive.md`，原檔開頭寫一行連結。
- 工作線結束後檔案留著，在開頭寫結束的日期和結論。
