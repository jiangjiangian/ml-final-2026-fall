## 切分和評分

- 01～07b 的切分：history 2020-01-02～2025-12-31（1,459 天）；fit 2026-01-02～07-14（125 天）；valid 07-15～10-08（60 天）；test = Phase 2 有答案的 10-12～11-10（20 天）；11-11 還沒答案。
- 08、09 的 12 個 fold：2024Q1～2026Q2 每季一個、2026Q3+（07-01～10-08）、phase2（10-12～11-10）。前 11 個當回測期（約 670～690 天），選擇只看這段；phase2 只報告。2026Q3+ 和 valid 重疊。
- 分數 = Top50 格子的 mean((2·pred − 1)·r)。全猜 0 = −mean(r)：valid −0.000723、Phase 2 −0.000395、08/09 回測期 +0.000457。95% 區間按日期 bootstrap 2,000 次。
- 訓練用全部 100 檔（`Top100@Y`），評分只算 `is_top50` 的 50 檔。樣本權重 |r| / mean(|r|)，所以機率 0.5 約等於 E[r] > 0。
- 特徵全部 shift(1)：t 那列只用 i（t 之前最後一個交易日）收盤後的值。01 驗過 `a_ret1` 和長表 `stock_ret_lag1` 最大差 5.9e-16。
