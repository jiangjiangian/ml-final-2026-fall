## 2026-11-22 集成和解封的研究

原始輸出在暫存資料夾 `bt/compare_1122/`（`wf2_inventory.md`、`wf2_prior.md`、`wf2_literature.md`、`inventory/`、`lit/notes_sources.md`），約 3 天後會被清掉，重點都在這節。

### 結論

- 集成只能合併成員已經有的資訊。沒有一個成員在開盤前猜得到大盤方向，所以集成生不出解封要的那一塊。
- 分數 = n·m + 選股，n = (猜漲 − 猜跌) ÷ 50。解封賺的是 n·m。最好的開盤前方向訊號猜對 52～54%（`07-decider-market-direction.md:456`），|m| 加權 0.54～0.58。
- 回本線（|m| 加權猜對率 w*，改檔數的成本取 `04-raw-feature-experiments.md:424` 的回測值）：±5 檔 0.504、全押 0.586。大波動期成本變大，±5 檔要 0.59～0.64，全押 0.645。大跌期正是改檔數最貴的時候。±10 檔的回本線兩個來源不一致（53.8% 和 53.3%），沒查清。
- 正式期跌最多的 11-16、11-19，前一晚的 O 都不大，開盤前沒有東西可以組合。

### 沒測過的

- N1：JS_ONLINE 放進 c2v2d 的排名集成當等權第四成員，β 傾斜和 p 不變。和 `X_price` 名次相關 0.774；兩者對 `X_price` 的贏面每天相關 0.38。直接前例是 BT 17b（B_knn150 第四成員 +0.0000892）。
- N2：跨群等權集成。不看答案的名次相關（Top50 1,155 天）分三群：表格群（`X_price`、X_inst、TabPFN、set）彼此 0.78～0.89；深度序列群（KD 02 deep_ens、KD 03 GATs、KD 07）0.76～0.90；長期平均群（trail96、KD 04、Chronos）0.67～0.99。深度序列群對長期平均群 0.33～0.42。JS_ONLINE、NB 夾在中間。深度和 Chronos 成員要 GPU，上不了 oop。
- U1：學出來的押法選擇器，目標是兩臂的差（全猜漲 − 25/25 = 1.223·m − s）。第三波提案保留但沒跑。
- U2：封頂的小檔數覆蓋（|n| ≤ 0.2，約 ±5 檔）疊在 c2v2d 上，方向用 c2v2d 的 p 和隔夜 O 的等權機率池，校準只用 2023 以前。O 和 p 幾乎獨立（corr(O, 2p−1) −0.20，方向一致 54%）；改檔數比換 β 便宜（MT 25）。最近的親戚 MT 名額 5（p 0.169）、BT 06 F3（p 0.10）都沒過。
