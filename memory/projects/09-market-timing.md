## 定義

- 分數：每天 50 檔的平均 (2·pred − 1)·r_i，r_i = 還原收盤 ÷ 還原開盤 − 1。等於 n·m 加上選股部分。
- m：當天 Top50 盤中報酬的平均（和 Decider 一樣）。
- n：淨比重 =（猜漲檔數 − 猜跌檔數）÷ 50。每天猜漲 k_t = 25 + 25·n_t 檔，取 `X_price` 排名的前 k_t 名。
- 調 n 的代價（`04-raw-feature-experiments.md` 第 23 節，回測 670 天，選股部分每天少多少）：n = 0.2 是 0.00001，0.4 是 0.00018，0.6 是 0.00039，1.0 是 0.00101。
- `X_price` 在 n = 0 已經暗中押跌：每天分數對 m 的斜率 −0.25（回測）、−0.33（Phase 2）；猜漲那半的 beta 比猜跌那半低 0.62（第 23、24 節）。
- 要贏的對照：固定 n = 0（現在交的），和「設計期挑出的最佳固定 n」。動態 n 只贏前者，可能只是學到平均偏跌。

### 改變研究方向的論點（d05 提出，d10、d16 同意，2026-11-14 00:25）
